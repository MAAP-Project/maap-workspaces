# maap-workspaces
Repository dedicated to building maap workspaces. 

All these images have MAAP extensions installed on top 

# Pangeo
Built from VEDA base image 

# Isce3
Published with the most recent version of the isce3 conda package 

# R
Built from rocker binder base image with important packages installed on top 

More documentation here: https://docs.maap-project.org/en/latest/system_reference_guide/create_workspace.html
